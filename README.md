# British Airways Passenger CSAT Dashboard

This project explores British Airways passenger reviews and customer satisfaction using an interactive Power BI dashboard.

## What the dashboard shows

- Overall review ratings and recommendation results
- Ratings for seat comfort, cabin crew, food, entertainment, ground service, and value for money
- Ratings by seat type and traveller type
- Review trends over time
- Reviews by country, continent, and aircraft
- Filters to explore different dates and passenger groups

## Project files

- `British Airways CSAT  Project Analysis.pbix` — the Power BI dashboard
- `ba_reviews.csv` — passenger review data
- `Countries.csv` — country and region data
- `Data Analysis - Passenger CSAT Dashboard.pdf` — project analysis document
- `Screenshot 1.png` to `Screenshot 4.png` — dashboard screenshots

## How to view the dashboard

1. Install [Microsoft Power BI Desktop](https://www.microsoft.com/power-platform/products/power-bi/desktop).
2. Open `British Airways CSAT  Project Analysis.pbix` in Power BI Desktop.
3. Use the filters on the report pages to explore the reviews.

This is a Power BI project, not a command-line application. Open the `.pbix` file to interact with the dashboard.
